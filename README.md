# SES-vs-PSO-Neural-Steering

Comparative analysis of Stochastic Evolutionary Strategy (SES) and Particle Swarm Optimization (PSO) for training neural network steering controllers in multi-robot path planning. Includes simulation environment, experimental results, figures, and statistical analysis demonstrating convergence, navigation efficiency, and robustness of SES over PSO.

This project demonstrates multi-robot coordination techniques along with the optimization comparisons.
